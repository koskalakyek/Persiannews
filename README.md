# ربات ساعتی اخبار اقتصادی/بازار ایران

این پروژه هر ساعت به‌صورت خودکار (با GitHub Actions):
1. از چند منبع خبری فارسی و بین‌المللی معتبر (`sources.json`) اخبار تازه اقتصادی **و سیاسی/ژئوپلیتیک مهم منطقه** می‌گیرد (چون تحولات سیاسی خاورمیانه هم روی بازار ایران اثر مستقیم دارد).
2. هر خبر را با Gemini API (رایگان) ترجمه/خلاصه کامل + تحلیل تاثیر بر بازار می‌کند.
3. بالای هر پیام یک نوار قیمت لحظه‌ای (دلار، طلای ۱۸ عیار، نفت برنت) از یک API واقعی اضافه می‌کند.
4. نتیجه را با ظاهری شبیه کانال‌های خبری بازار (تیتر پررنگ، ایموجی، جداکننده) به یک کانال تلگرام ارسال می‌کند.

📌 یک نکته صادقانه: من به کانال تلگرامی که مثال زدی (`t.me/rasadaiofficial`) دسترسی مستقیم نداشتم تا قالب دقیقش را کپی کنم، برای همین یک قالب تمیز و حرفه‌ای مشابه سبک کانال‌های خبر بازار طراحی کردم (تیتر، برچسب دسته‌بندی، خلاصه، تحلیل، لینک، همه با ایموجی و جداکننده). اگر قالب دقیق‌تری در ذهن داری (مثلاً رنگ‌بندی ایموجی خاص یا چیدمان متفاوت)، بگو تا `build_prompt` در `scripts/fetch_and_post.py` را دقیقاً مطابق آن تنظیم کنم.

⚠️ **این ابزار مشاور مالی یا حقوقی نیست.** خروجی آن یک خلاصه‌خبری و تحلیل کمکی است، نه توصیه قطعی برای خرید/فروش. مسئولیت تصمیم‌های مالی همیشه با خود شماست.

---

## مرحله ۰ — تست نوار قیمت لحظه‌ای (خیلی مهم)

بالای هر پیام یک نوار قیمت شامل دلار (بازار آزاد)، طلای ۱۸ عیار و نفت برنت نمایش داده می‌شود. این قیمت‌ها از یک وب‌سرویس رایگان ایرانی (BrsApi.ir) و Yahoo Finance گرفته می‌شوند و هرگز توسط هوش مصنوعی حدس زده نمی‌شوند. چون ساختار دقیق این وب‌سرویس‌ها می‌تواند تغییر کند، قبل از هر چیز اجرا کن:

```bash
pip install -r requirements.txt
cd scripts
python test_prices.py
```

اگر یکی از مقادیر «نامشخص» بود، همان‌جا JSON خام چاپ می‌شود؛ با نگاه به آن، شرط‌های `find_item` در `scripts/price_ticker.py` را با نام فیلد واقعی تطبیق بده (چند خط ساده پایتون است).

## مرحله ۱ — تست منابع خبری (خیلی مهم)

آدرس فید RSS سایت‌های خبری (به‌خصوص ایرانی) گاهی تغییر می‌کند. قبل از فعال کردن ربات، این دستور را اجرا کن:

```bash
pip install -r requirements.txt
python scripts/validate_sources.py
```

هر منبعی که ❌ FAIL شد را در `sources.json` اصلاح یا حذف کن. اگر منبع معتبر دیگری (مثل خبرگزاری‌های تخصصی، سایت بانک مرکزی، یا سایت رسمی بورس تهران) می‌شناسی که فید RSS دارد، همان‌جا اضافه‌اش کن. فیلد `always_include: true` یعنی «همیشه این منبع ارسال شود، بدون نیاز به تطابق کلیدواژه» — برای منابع رسمی/درجه‌یک مناسب است.

## مرحله ۲ — ساخت بات تلگرام و کانال

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده و با `/newbot` یک بات بساز؛ توکن (Token) را نگه دار.
2. یک کانال عمومی بساز (یا از کانال موجودت استفاده کن).
3. بات را به‌عنوان **ادمین** کانال اضافه کن (حداقل با دسترسی ارسال پیام).
4. شناسه کانال معمولاً همان `@your_channel_username` است (اگر کانال یوزرنیم عمومی ندارد، باید عددی chat_id را از طریق APIهایی مثل `getUpdates` پیدا کنی).

## مرحله ۳ — گرفتن کلید رایگان Gemini API

1. به [Google AI Studio](https://aistudio.google.com/apikey) برو و یک کلید API رایگان بساز (نیازی به کارت اعتباری نیست).
2. مدل پیش‌فرض این پروژه `gemini-2.5-flash` است. مدل‌های Gemini مدام به‌روز می‌شوند و ممکن است در آینده منسوخ شوند؛ اگر روزی خطای «model not found» گرفتی، به [صفحه مدل‌های Gemini](https://ai.google.dev/gemini-api/docs/models) سر بزن، اسم مدل رایگان جدید را بردار و در مرحله بعد به‌عنوان مقدار متغیر `GEMINI_MODEL` قرار بده.

## مرحله ۴ — آپلود پروژه در GitHub

1. یک ریپازیتوری جدید (می‌تواند خصوصی/Private باشد) در GitHub بساز.
2. تمام فایل‌های این پروژه (شامل پوشه‌ی مخفی `.github`) را در آن آپلود/پوش کن.
3. برو به **Settings → Actions → General → Workflow permissions** و گزینه‌ی **Read and write permissions** را فعال کن (لازم است تا ربات بتواند فایل `seen.json` را به‌روزرسانی کند و اخبار تکراری نفرستد).

## مرحله ۵ — تنظیم Secrets

در ریپازیتوری برو به **Settings → Secrets and variables → Actions** و این Secretها را بساز:

| نام Secret | مقدار |
|---|---|
| `GEMINI_API_KEY` | کلید API که در مرحله ۳ گرفتی |
| `TELEGRAM_BOT_TOKEN` | توکن بات از BotFather |
| `TELEGRAM_CHANNEL_ID` | مثلاً `@your_channel_username` |

اگر خواستی مدل Gemini را تغییر بدهی، در همان صفحه بخش **Variables** یک متغیر با نام `GEMINI_MODEL` بساز (اختیاری؛ در غیر این صورت پیش‌فرض `gemini-2.5-flash` استفاده می‌شود).

## مرحله ۶ — اجرا

ربات به‌صورت خودکار هر ساعت (دقیقه صفر، به وقت UTC) اجرا می‌شود. برای تست فوری، به تب **Actions** در گیت‌هاب برو، وارد ورک‌فلوی `Hourly Iran Market News Bot` شو و روی **Run workflow** بزن.

## ساختار پروژه

```
sources.json                    # لیست منابع خبری + کلیدواژه‌های فیلتر
seen.json                       # حافظه اخبار قبلاً ارسال‌شده (خودکار به‌روزرسانی می‌شود)
requirements.txt                # وابستگی‌های پایتون
scripts/fetch_and_post.py       # منطق اصلی: دریافت خبر → تحلیل با Gemini → ارسال به تلگرام
scripts/price_ticker.py         # ساخت نوار قیمت دلار/طلا/نفت برنت (از API واقعی، نه هوش مصنوعی)
scripts/validate_sources.py     # تست سلامت فیدهای RSS
scripts/test_prices.py          # تست دستی نوار قیمت قبل از استقرار
.github/workflows/hourly-news.yml  # زمان‌بندی اجرای ساعتی در GitHub Actions
```

## تنظیمات قابل تغییر (متغیرهای محیطی اختیاری)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `LOOKBACK_MINUTES` | 90 | اخبار قدیمی‌تر از این مدت (به‌جز اخبار جدید) نادیده گرفته می‌شوند |
| `MAX_ARTICLES_PER_RUN` | 10 | حداکثر تعداد خبر در هر اجرا (برای رعایت محدودیت رایگان Gemini) |
| `GEMINI_MIN_INTERVAL_SECONDS` | 7 | فاصله بین درخواست‌های Gemini برای جلوگیری از خطای rate limit |

## نکات اعتبارسنجی خبر

- منابع به‌صورت دستی و با دقت انتخاب شده‌اند (خبرگزاری‌های رسمی داخلی، رسانه‌های اقتصادی شناخته‌شده داخلی، و رسانه‌های بین‌المللی معتبر).
- به هوش مصنوعی دستور داده شده که اگر خبر شکل شایعه/تاییدنشده دارد، صراحتاً هشدار «نیاز به تایید بیشتر» بدهد.
- برای اطمینان بیشتر از یک خبر مهم، همیشه لینک منبع اصلی که در پیام تلگرام قرار می‌گیرد را باز کن و در صورت امکان با منبع دوم مقایسه کن؛ هیچ سیستم خودکاری جایگزین قضاوت نهایی خودت نیست.
